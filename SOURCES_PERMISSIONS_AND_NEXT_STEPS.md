## Photo usage

- The website currently provides links to the original SANIT materials instead of copying SANIT-owned photos or videos.
- Request written permission from the owner/rightsholder before embedding, downloading, cropping, republishing or re-hosting their corporate photos/videos in a personal portfolio.
- Once permitted, add files to `assets/approved-photos/`, update the portfolio image areas and credit each image appropriately.
- Do not present any corporate gallery photo as a photo from a work package that Alice personally managed without supporting documentation.

## Facts to verify before including stronger project claims

- Exact named SANIT project/site(s) and months of participation.
- Real project responsibilities under supervisor oversight.
- Approved water-pipe quantities, diameters and installation methods.
- Available drawing revisions / mapping excerpts released for publication.
- Specific measurement and cost-control deliverables personally handled.
- Project-specific measured outcomes, completed scope and dates.
- Irish work authorisation / driving licence recognition / Irish standards training, if later obtained.

## GitHub publishing

1. Create a GitHub account at https://github.com/ (if not already created).
2. Create a public repository named `water-infrastructure-portfolio`.
3. Upload the **contents** of this folder to the repository root (not the ZIP itself).
4. Under repository **Settings > Pages**, select **Deploy from a branch**, `main` and `/ (root)`.
5. When GitHub Pages completes deployment, the expected address is `https://YOUR-USERNAME.github.io/water-infrastructure-portfolio/`.
6. To add a profile biography, create a repository named exactly as your username; copy the contents of `GITHUB_PROFILE_README.md` into its `README.md`, replacing `YOUR-USERNAME`.
7. Pin your portfolio repository on your GitHub profile and add the GitHub Pages link to the optional recruitment form field.

**The supplied GitHub links are templates only; no public account or live repository has been created.**
